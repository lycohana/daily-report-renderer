## Claude Code 3.0发布 代码能力超越GPT-5
Anthropic今日发布Claude Code 3.0，在SWE-bench测试中达到92.3%的准确率，首次超越GPT-5的89.1%。新版本增强了代码解释、调试和重构能力，支持20+编程语言。

Claude Code 3.0还引入了"代码审查"功能，可自动识别安全漏洞和性能问题，帮助开发者写出更高质量的代码。

## DeepSeek V3开源 性能逼近GPT-4.5
DeepSeek今日开源V3版本，在MMLU、HumanEval等基准测试中表现优异，多项指标逼近GPT-4.5。V3采用全新的MoE架构，推理效率提升40%。

作为开源模型，DeepSeek V3允许企业本地部署，降低了AI应用的成本门槛。社区反响强烈，发布24小时内GitHub星标已突破1万。
